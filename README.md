# Python Photo Slideshow Album

A simple desktop Photo Slideshow Album developed using Python.

## Features
- Displays multiple images.
- Automatically changes images every 2 seconds.
- Resizes images to 700x700.
- Simple graphical user interface.

## Technologies Used
- Python
- Tkinter
- Pillow (PIL)

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python main.py
